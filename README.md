# rugbyApp
Rugby Recaps Recommendation App

## intro

This is the project for the Fall 2026 cohort of the The Vibe Coding Studio by Phillip Compeau -- https://www.philomathlearning.com/studio

## idea

The app will be hosted as a static website. The idea is to give each game a score that shows how entertaining it was. No spoilers, no actual game scores or any hints on who won the game are allowed.
